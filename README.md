# Tuesday 17 November 2026: 42 stories, 6 continents, one front page

A dense newspaper front page summing up the world news of Tuesday
17 November 2026 in one image (`entry.png`, 1024x1024 JPEG bytes,
269,537 bytes). The date is the masthead; below it, 3 lead stories,
12 illustrated cards, a "WHERE IT HAPPENED" world map with numbered
pins, 27 more stories in "ALSO ON TUESDAY", a DATE CHECK box, and a
verification footer with sources.

The image is rendered programmatically (`render_frontpage.py`, PIL
only, deterministic — no AI image generation, so every headline is
exactly as written here). Resubmission (round 2) of the round-1 entry,
which had only 6 stories; this version rebuilds it as a dense front
page following the winning formula: date masthead, story count,
leads, cards, map, ALSO list, sources.

## How it runs

`render_frontpage.py` (PIL, build time only) draws `entry.png`
deterministically from the story list in that file — no randomness,
no time, no network; fixed JPEG quality 88.

`main.py` (Python 3.13, standard library only, no network) copies
`entry.png` to `$MAKEFUN_OUTPUT_DIR/entry.png` (default `/output`),
authenticating the source first (size, SHA-256, JPEG SOI/EOI
markers), hashing while copying, and re-reading the delivered file
afterwards. Any mismatch exits non-zero. Run it twice and the two
outputs are byte-identical.

Validation (round 2, 18 Nov 2026): `entry.png` JPEG, 1024x1024,
RGB, 269,537 bytes (<= 1,048,576), full decode OK (PIL `load()`),
SHA-256 `d8a8fe07f0a356b1bae86c3073cd46131babbb78d8b581294ee47c46dae95ac7`.
`main.py` run 1 and run 2 both wrote 269,537 bytes with the same
SHA-256 — byte-identical to each other and to the shipped file.
